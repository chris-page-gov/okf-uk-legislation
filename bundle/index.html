    Official source and limitations

    Use legislation.gov.uk and its official data documentation to verify current legal text, commencement, extent, amendments and unapplied effects. See the official data.gov.uk API documentation and the published GOV.UK CKAN OKF example for related discovery patterns.

    To create another bundle, use the copy-ready OKF Foundry authoring and domain profiles guide. This independent prototype is not legal advice or qualified practitioner assurance.

    GitHub Pages currently serves .yamlld as application/octet-stream. The YAML-LD bytes remain semantically validated; JSON-LD and immutable release downloads are the strict transport fallbacks until a permanent host can serve application/ld+yaml.
