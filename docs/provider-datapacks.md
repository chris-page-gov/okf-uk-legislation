# Provider datapacks

A provider datapack records a bounded review of an external reference, with its source and snapshot identity. It does not establish that an external service is current or legally authoritative.

This local navigation page supports relative links in the unchanged vendored
profile. It is not a copy of the upstream specification. Read the
[pinned Explorer documentation](https://github.com/chris-page-gov/okf-explorer/blob/4bb7b92a64b7ba69bde9b1e86786217338cd166d/docs/provider-datapacks.md)
for the exact version associated with the
[vendor lock](../profiles/bundle-wiki/v1.vendor-lock.json).

See the [legislation candidate status](profile-reconciliation-2026-09.md) for
this repository’s validation and publication limits.
